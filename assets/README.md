# /assets

Pasta reservada para assets estáticos do projeto.

## O que vai aqui

- SVGs otimizados (logotipo, ícones, ilustrações)
- Imagens do produto (screenshots, mockups)
- Favicon e metaimagens (og:image, twitter:card)

## Regras

- Não commitar fontes proprietárias (ex: Noopla) sem autorização formal
- Imagens externas não autorizadas não devem entrar neste diretório
- Preferir SVG sobre PNG/JPG sempre que possível
- Nomear arquivos com kebab-case: `icone-agente.svg`, `logo-inbot.svg`

## Status atual

Aguardando assets oficiais da InBot (logotipo, ícones, imagens de produto).
